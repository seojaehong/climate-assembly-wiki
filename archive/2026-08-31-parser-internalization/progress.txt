### rhwp WASM 을 Node 에서 띄우는 법 (실측 확인)
```js
import { createRequire } from 'node:module';
import { readFile } from 'node:fs/promises';
const require = createRequire(import.meta.url);
const wasmPath = require.resolve('@rhwp/core/rhwp_bg.wasm');  // exports 필드가 없어 서브패스가 통한다
await (await import('@rhwp/core')).default({ module_or_path: await readFile(wasmPath) });
```
- ★ **스크립트를 스크래치패드에 두면 `MODULE_NOT_FOUND`** 다. 모듈 해석이 스크립트 위치 기준이라 **저장소 안에서 실행**해야 한다

- **★ `core.autocrlf=true` 다.** 바이트가 중요한 파일(서드파티 사본·픽스처)은 `.gitattributes`
  에 `-text` 로 못박는다. `git add` 가 "LF will be replaced by CRLF" 경고를 뿜으면 신호다.
- **★ JSON 을 문자열 치환으로 고칠 때 값은 `json.dumps(..., ensure_ascii=False)` 에 맡겨라.**
  손으로 `\"` 를 적으면 위의 heredoc 역슬래시 함정과 겹쳐 파일이 깨진다(`prd.json` 을 한 번 깨뜨렸다).
