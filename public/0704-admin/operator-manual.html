0704 현장 운영

시트입력 · 폼입력 · 출력 매뉴얼

복잡한 명령어 없이, 메뉴와 QR 기준으로만 정리했습니다. 현장 담당자는 본인 역할 카드만 보면 됩니다.

관리자 메뉴

1. 시트입력

13~16시에는 기록모더레이터가 A조/B조만 입력합니다.

들어갈 곳아래 A/B 입력 Sheet 버튼 또는 관리자 메뉴의 실시간 입력 Sheet
A조 담당A조 질문입력, A조 의제입력 탭에 입력
B조 담당B조 질문입력, B조 의제입력 탭에 입력
입력 방식질문은 질문 탭에, 투표 후보 의제는 의제 탭에 한 줄씩 입력
A/B 입력 Sheet

2. 폼입력

기본 질문 수합은 A/B 입력 Sheet입니다. 진행자가 직접 QR 입력을 안내할 때만 Form을 씁니다.

탄소 감축 질문참여단 직접 QR 입력을 지시할 때만 전문가에게 묻고 싶은 질문을 Form으로 입력
조별 의제 입력조별로 투표 후보가 될 의제 입력
의제투표최종 후보가 정리된 뒤 참여단이 투표
소감발표17시 이후 전체 공유용 소감 입력. 1~17조 + 연구진 중 선택
QR 보기 URL 보기

3. 출력

출력 담당자가 관리자 메뉴에서 PDF를 열어 인쇄합니다.

들어갈 곳관리자 메뉴의 A/B 실시간 Sheet 입력 또는 현장 인쇄본 일괄 갱신
전체 갱신콘솔컴에서 pwsh -NoProfile -ExecutionPolicy Bypass -File scripts\sync-0704-live-operation.ps1 -Deploy 실행
질문 전달질문 보드는 전문가 화면에 띄우고, Sheet 질문 PDF는 인쇄용으로 사용
의제 출력Sheet 의제 PDF 버튼을 열고 인쇄
결과 화면결과 버블레이스 버튼을 열어 발표 화면에 띄움
질문 PDF 질문 보드 의제 PDF 의제 보드 버블레이스

QR 기준 폼입력

현장 화면에는 관리자 메뉴의 QR을 띄워도 되고, 이 매뉴얼을 출력해 QR만 나눠도 됩니다.
