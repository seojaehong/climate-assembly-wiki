## II. 현재 5 기준 강·약점 요약

| 기준 | 강점 | 약점 |
|---|---|---|
| 1.기후 직접성 | 모든 국제사례 채택 | 정의 모호("직접"의 경계) / 간접영향(순환경제·정의전환) 배제위험 |
| 2.법령 정합성 | 법체계 일관성 / 이진우 게이트 = 시간절약 | 부산적 — 우선순위 아닌 제약일 뿐 / 법령자체가 기후정의 불충분 시 순환논리 |
| 3.일상 체감 | 시민 동의·참여동기 | **측정 불가능** / 도시 편중·농어촌 배제 / 취약계층과 충돌 |
| 4.사회적 합의 필요 | 모든 사례 ✓ / 정책수용성 | **역순환 위험** — 저충돌 의제 편중 / 고갈등(탈석탄·핵폐기) 배제 |
| 5.대안 시나리오 | 권고 실행성 / 민주적 | 정의 추상 / 패러다임 전환의제 배제 / 6회로 실현 곤란 |

## IV. 권고안↔의제 기준 일관성 갭

**갭 2건 발견**:

1. **정의로운 전환** (권고안 ②) ↔ 의제기준 누락 → "불공정한 의제" 선정 위험 (정의 미고려 탈석탄 등)
2. **미래세대 정의** (권고안 ④) ↔ 의제기준 누락 → "현세대 이익만 반영" 위험

→ **권고안 기준은 미래세대·정의를 묻는데, 의제선정은 안 묻는 구조적 결함**

## V. 최종 권장 (개선안 B — 5 유지 + 강화)

### 강화된 5 기준

#### 기준 1. 기후·정책 정합성 (가중치 40%)
- 기후영향(직접/간접/단기/장기 매트릭스)
- 탄소중립기본법·부령 범위
- **2035 NDC / IPCC 1.5℃ 경로 정합도** ← 신규
- 출처: OECD / KNOCA / 탄소중립위

#### 기준 2. 정의로운 의제화 (가중치 30%) ← 신규 통합
- 대상인구 대표성(지역·계층·연령)
- **미래세대 누적영향 20년+** ← 신규
- 취약계층 적응·완화 분담율 (형평성)
- 정의로운 전환 고려도 (재정·고용)
- 출처: Carnegie 10원칙 / WRI / FR / 권고안 ②④

#### 기준 3. 사회적 필요성 (가중치 15%)
- 이해관계 집단수 ≥3
- **갈등 심화도 (高일수록 가중)** ← 신규: 저충돌 편중 방지
- 정책수용성 영향도
- 사회적 학습 기회도
- 출처: 신고리 평가 / OECD / 이진우안

#### 기준 4. 시민 참여 적합성 (가중치 10%)
- 가능 대안 시나리오 2-5개
- 의제 기술 난이도 (입문/중간/고도)
- 추정 숙의시간 (4/6/8h+)
- 시민 학습곡선 회차별 예측
- 출처: newDemocracy / KNOCA / UK

#### 기준 5. 실행 기반 성숙도 (가중치 5%) ← 신규
- 정책주체 명시(중앙/지자체/민간)
- 예산 편성 가능성
- 실행 타이밍 (즉시/1년/중기)
- 과학적 합의도 (H/M/L)
- 증거기반 준비도
- 출처: OECD Implementation / IE / 신고리 / Carnegie

### 의제선정 후 보완 체크리스트
- 시민학습 체크리스트 (의제당 시간 할당)
- 증거·데이터 준비도
- 권고안-의제 일관성 맵

## VI. 의제 선정 흐름

```
의제 공모
  ↓
기준 1-5 평가 (외부자문단 10 + 기획참여단 20)
  ↓
점수 산출 (Weighted Scoring)
  ↓
상위 N개 선정 (숙의참여단 학습 가능 수)
  ↓
의제별 시민학습 체크리스트 (회차 할당)
  ↓
전문가·증거 준비도 검토
  ↓
권고안 기준 예비 매칭
  ↓
숙의참여단 학습·숙의 (4-6회)
  ↓
권고안 도출 + 정부 이행 추적
```
