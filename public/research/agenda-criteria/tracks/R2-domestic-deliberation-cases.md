## 1. 신고리 5·6호기 (2017)
- **의제**: 단순 찬반(건설중단 vs 재개) + 보조(원자력 축소/유지/확대)
- **시민참여단** 471명 / 2박3일 합숙 / 4차 설문
- **결과**: 재개 59.5% vs 중단 40.5%
- **운영규정**: 총리훈령 §690 — 의제선정 원칙 명시 없음, 위원장(김지형) 재량
- **비판**:
  - 이영희(2018) "시간부족·대표성결여·기울어진 운동장 + 44조 매몰비용 무의식 영향"
  - 김길수(2018) "기계적 평등 ≠ 비례적 평등 — 국내 전문가 분포 미보정"
- 출처: [이영희(2018)](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002313630), [김길수(2018)](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002358847)

## 2. 사용후핵연료 (2013-15, 2018 재검토)
- **609일 운영** / 정부 주도 6 처리방식 제시
- **비판** (이준문 2014): ①독립성·중립성 부족 ②한시성·법적지위 불명확 ③최종권고안 문서화 미흡 ④제도화 부재 → 2018 재검토에서 원점 회귀
- 출처: [이준문(2014)](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002431414)

## 3. 대입제도개편 (2018)
- **시나리오 워크숍** → 3쟁점 → 4시나리오 압축
- **시민참여단 490명**
- **비판** (장현주 2021): "의제 2(절대평가) ↔ 의제 4(절대평가+비교과폐지) 중복 → 시민 일관된 선호 불가" → **의제 상호배타성 원칙 위반**
- 출처: [장현주(2021)](https://www.dbpia.co.kr/journal/articleDetail?nodeId=NODE11311655)

## 4. 연금개혁 (2024)
- **의제숙의단 50명** → 의제 워크숍 → 6개 주제 확정
- **시민대표단 500명** → 56% 소득보장안 선택
- **비판**: 정부가 의제숙의단 6개 → 2개 대안으로 압축, 원래 권고 방향 미기록
- 출처: [공론화 백서](https://nsp.nanet.go.kr/plan/subject/detail.do?newReportChk=list&nationalPlanControlNo=PLAN0000048241)

## 5. 기후시민회의 지방 시범 (2026)

## 한국 공론화 의제선정 5 설계 원칙 (R2 도출)

### 원칙 1. 명시적 의제적격성 심사 (Eligibility Test)
- 정책성(정부/의회 결정권) + 시민참여성(가치선택) + 이해다원성(≥3 진영)
- 근거: 이상급(2019), 강지선(2025), 신고리 사후비판

### 원칙 2. 의제숙의단 독립성 보장 (Autonomy)
- 50-70인 정부·시민 혼합 / 정부는 쟁점만 제시 / 의제 구성은 숙의단 완전 주도
- 근거: 2024 연금개혁 "정부 압축" 비판 + Cobb&Ross 주도집단 명확화

### 원칙 3. 이해충돌 관리 & 전문가 비례 (Conflict & Balance)
- 기계적 평등이 아닌 **실제 의견 분포 반영 비율**
- Baseline Survey + 숨겨진 이해충돌(매몰비용·산업친화) 명시 고지
- 근거: 김길수(2018) 신고리 비판

### 원칙 4. 의제 상호배타성 (Mutually Exclusive)
- 부분중복 의제 통합/제외 + 의제수 ≤3-4개
- 근거: 장현주(2021) 대입제도 분석

### 원칙 5. 결과반영 메커니즘 사전공시 (Pre-commitment)
- **강한**: ≥50% → 정책변경 의무
- **중간**: 의회/위원회 보고 후 검토
- **약한**: 정책참고 (정보제공만)
- 불이행 시 책임부서 공개
- 근거: 황수경(2020) "Outcome Acceptance" + 사용후핵연료 신뢰추락
