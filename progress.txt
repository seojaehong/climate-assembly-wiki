  Node 24 는 astro build 가 무출력 사망
- `npm run build` = prebuild + astro + postbuild. `npx astro build` 만 쓰면 postbuild 훅이 안 걸려
  `dist/deployment-revision.json` 이 안 생긴다
- ★ **prebuild 가 `index.md`·`log.md`·`public/workshop-graph/data/*.json` 을 재생성해 워킹트리를 더럽힌다.**
  커밋 전에 `git checkout` 으로 되돌릴 것
- `package.json` 에 `test` 스크립트가 **없다**. `npx vitest run` 을 쓴다
- **테스트 기준선 = 90 파일 / 1,516 테스트 전부 통과** (2026-08-31, 이 브랜치 시작 시점)
- ★ **`.tsx` 테스트는 vitest include 에 안 잡혀 조용히 통과한 것처럼 보인다.**
  검증할 판단 로직은 반드시 `.ts` 로 뺀다 (`src/islands/mod/AGENTS.md` 파일 짝 규칙)
- 검증 규약: `scripts/verify-*.mjs` — **N/N 개수로 출력**, DB 에 쓰지 않는다

  `pathToFileURL()` 로 import** 할 것
- **의존성 설치**: `npm install --omit=optional` **금지**. rollup·esbuild·lightningcss 네이티브 바이너리가
  빠져 `astro build` 가 `Cannot find module '@rollup/rollup-win32-x64-msvc'` 로 죽는다
