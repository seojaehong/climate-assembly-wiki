### rhwp WASM 을 Node 에서 띄우는 법 (실측 확인)
```js
import { createRequire } from 'node:module';
import { readFile } from 'node:fs/promises';
const require = createRequire(import.meta.url);
const wasmPath = require.resolve('@rhwp/core/rhwp_bg.wasm');  // exports 필드가 없어 서브패스가 통한다
await (await import('@rhwp/core')).default({ module_or_path: await readFile(wasmPath) });
```
- ★ **스크립트를 스크래치패드에 두면 `MODULE_NOT_FOUND`** 다. 모듈 해석이 스크립트 위치 기준이라 **저장소 안에서 실행**해야 한다
- `globalThis.measureTextWidth` 스텁은 **불필요**하다(텍스트 추출만 할 때). 렌더할 때만 필요

### ★ getTextFileText() 반환값은 JSON 인코딩 문자열이다
「역슬래시 이스케이프 2문자」로 보이는 것의 정체다. 첫 글자와 끝 글자가 `"` 이고 **통째로 `JSON.parse` 가 된다**(두 대상 파일 모두 성공).
- 정책권고안 hwpx : raw 2,261자 → parse 후 **2,002자**
- A조 결과보고서 hwp : raw 28,504자 → parse 후 **25,320자**
→ `JSON.parse` 를 1순위로, 실패할 때만 리터럴 `` `
` 치환을 폴백으로 둔다.

### HTML 엔티티는 parse 이후에도 남는다
숫자 엔티티만 관측됐다 — hwpx `&#8212;`, A조 `&#8199;` `&#61580;` `&#61581;` `&#57430;`(사용자정의 영역 = 윙딩 불릿).
**숫자 엔티티 디코드 필수**, 이름 엔티티는 미관측.

- **의존성 설치**: `npm install --omit=optional` **금지**. 트리 전체에 걸려 rollup·esbuild·
  lightningcss 네이티브 바이너리까지 빠지고 `astro build` 가
  `Cannot find module '@rollup/rollup-win32-x64-msvc'` 로 죽는다. 평범한 `npm install` 을 쓰고,
  무거운 것은 `postinstall` 의 `scripts/prune-kordoc-optionals.mjs` 가 지운다(~697MB).
- **`sharp` 는 astro 것**이다(이미지 서비스). 최상위 `sharp`·`@img` 를 지우면
  `Rollup failed to resolve import "sharp"` 로 빌드가 죽는다. kordoc 은 ^0.35 를 요구해
  `node_modules/kordoc/node_modules/` 아래 사본이 따로 생기고, 지워도 되는 건 그 중첩 사본뿐.

  Node 24 에서는 astro build 가 출력 없이 죽는다.
- **검사 3종**: `npx tsc --noEmit -p tsconfig.json` · `npx vitest run`(86파일 1473테스트) ·
  `npx astro build`(7916 페이지, 약 60초).

  "디렉터리는 있는데 MODULE_NOT_FOUND" 인 상태가 만들어진다. 이러면 `npm install` 을 다시 돌린다.

  베끼지 않고 **esbuild 로 .ts 를 그 자리에서 변환해 import** 한다 — 새 스크립트도 이 방식.
- **커밋 제외 — prebuild 타임스탬프 churn**: 빌드를 돌리면 `index.md`(Last generated) ·
  `log.md` · `public/workshop-graph/data/{agenda-surface,kb-agenda-surface}.json`(generated_at)이
  매번 바뀐다. story 와 무관하므로 커밋에 넣지 않는다(US-001 커밋도 뺐다).
- **`rm -rf` 는 거부된다**: 임시 디렉터리 정리는 `git clean -fd <경로>` 로 한다.
- **★ 동시 실행 주의 (2026-08-30 20:26 실측)**: `ralph.sh` 루프가 **2개**(pid 30373 20:04 시작 ·
