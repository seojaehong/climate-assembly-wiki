# 9/12–13 Zoom 논의 기반 시스템 제안

## 바로 반영하지 않고 제안으로 보류할 항목

1. 세션마다 입력·수정·저장 이력을 빠짐없이 남기고, 종료 뒤 전체 기록을 한 번에 내려받는 기능을 정식 요구사항으로 둔다.
2. 주제는 현장에서 추가·수정할 수 있게 하되, 누가 바꿨는지와 담당 모더레이터를 함께 표시한다.
3. 하나의 조 의견이 여러 권고안에 연결될 수 있게 하고, 연결 근거를 운영 화면에서 확인하게 한다.
4. 중복으로 판단된 의견도 삭제하지 않고 `중복 관계`와 `보완 의견`을 구분해 원문을 보존한다.
5. 조별 자동 배정 현황을 시민 화면에 공개하지 않는다. 운영진 검토용 제안으로만 제공한다.
6. A·B·C·D 유형은 확정 규칙이 아니므로 코드에 고정하지 않는다. PM 확정 뒤 데이터 정의와 예외 규칙을 별도 반영한다.
7. `관련 조`는 확인된 조만 표시하고, 추정 연결은 검토 대기 상태로 분리한다.
8. 9/13 화면은 그룹핑 작업에 집중하고 최종 대표 제목·권고문 확정 기능은 분리한다.

## PM 확인이 필요한 구체 안건

1. 최종 산출물 마감일은 10월 17일인가요, 10월 27일인가요?
2. 조별 최소 제안 수는 2개인가요, 4개인가요?
3. 최종 분과별 권고안 수 `9·8·8`과 관련 조 매핑을 누가 확정하나요?
4. 세션 전체 기록의 정본 형식은 HWP, DOCX, XLSX, ZIP 중 무엇이며 최종 소유자는 누구인가요?

이 문서는 녹취 검토 결과를 시스템 관점에서 제안으로 정리한 것으로, PM 확인 전에는 운영 데이터 구조나 화면 규칙에 자동 반영하지 않는다.
