# 11/14 전체회의 의결 투표지 만들기 (운영자 1쪽)

11/10 결정: 투표지 3장은 의제(분과) 단위로 나누되, 분과 지정으로 투표 대상을 좁히지 않는다. 출석자 전원이 세 장 모두에 투표한다.

11/10 주최 결정(확정): ① 기권 불인정 — 모든 건을 눌러야 제출된다 ② 「직접 입력」 이름도 유효표(방어선: 출석부의 같은 조 · 이름과 맞을 때만 센다) ③ 같은 이름으로 이미 낸 사람은 재투표 불가 ④ 「세부권고 보기」 접기는 넣지 않음.

## 0. 하루 전 사전 점검 (하나라도 빠지면 투표지를 열지 않는다)

1. **세션 명단이 들어가 있는가.** 명단은 세션 단위로 둔다. 11/10 기준으로 11/14 세션에는 명단이 없다.
   - 명단이 비면 `/b`는 전체회의 의결 투표지(제목이 「전체회의 의결」로 시작)를 열자마자 「명단이 아직 준비되지 않았습니다 … 진행요원에게 알려 주세요」 화면으로 막고 제출을 받지 않는다(무기명으로 내지 않는다). 명단을 넣은 뒤 그 화면의 「다시 확인」을 누르면 조·이름 고르기부터 시작한다.
   - 넣기: `npx tsx scripts/load-1017-roster.ts --roster <명단.json> --map "<11/14 세션 슬러그>=1분과,2분과,3분과"`. 미리보기로 수를 확인한 뒤 같은 명령에 `--apply`를 붙인다. 명단 파일은 저장소 밖에 둔다.
   - 기획참여단 명단도 같은 세션에 넣으면 한 사람이 조 이름만 다른 두 행이 될 수 있다. 넣기 전에 겹치는 이름이 있는지 대조한다.
2. **세션 접속 기한(access_expires_at)이 11/14 행사 종료 뒤인가.** 지나면 명단 조회와 제출이 모두 막힌다.
3. **실명 수집이 켜져 있는가.** `session.config.named_vote.collect`이며 기본은 켜짐이다. 꺼져 있으면 명단이 있어도 1번과 같은 막는 화면이 뜬다. 투표 중에 끄면 그 뒤 제출하는 사람도 막힌다.
4. **휴대폰으로 투표지를 한 번 열어 본다.** 「먼저 조와 이름을 눌러 주세요」 화면이 뜨고, 조 단추가 「1분과 1조 … 3분과 5조」로 전원 나와야 한다. 「명단이 아직 준비되지 않았습니다」가 뜨면 명단이 없거나 실명 수집이 꺼진 것이다.
5. **문항이 모두 필수로 만들어졌는가 — 결과 내보내기로 확인한다.** 서버는 문항의 필수 표시로만 빈 건을 막는다. 휴대폰 화면은 전체회의 투표지면 필수 표시와 관계없이 빈 건을 막으므로, 휴대폰으로 한 건을 비워 보는 것으로는 필수 표시를 확인할 수 없다.
   - 열어 둔 리허설 투표지로 결과 내보내기(`confirmed: false`)를 한 번 돌린다. 「필수가 아닌 문항」으로 거부되면 「누르지 않은 건 허용」(옛 판 폼 포함)으로 만든 투표지다 — 지우고 다시 만든다.
   - 내보내기는 초안 투표지의 필수 표시를 읽지 못한다(열린 · 마감 · 공개만). 실전 투표지 3장은 열자마자 같은 방법으로 한 번씩 돌려 거부되지 않는지 본다.
   - 휴대폰에서는 한 건을 비우면 요약 화면의 [제출하기]가 꺼지고 「누르지 않은 권고안 ○-○부터 고르기」 단추가 뜨는지 본다(화면 차단 확인).

## 1. 만드는 곳

운영 콘솔 `/mod`(11/14 세션 운영자 접속)의 「투표」 탭에서 [＋ 새 다의제 투표]를 연다. 분과가 없는 운영 조로 접속하는 것을 권한다.

## 2. 넣는 값 (투표지 1장마다)

| 칸 | 값 |
| --- | --- |
| 투표 제목 | `전체회의 의결 의제1 기업 온실가스 감축 촉진`, `전체회의 의결 의제2 …`, `전체회의 의결 의제3 …`. 앞부분 「전체회의 의결 의제N」은 글자 그대로 쓴다. 「의제」 뒤에 띄어쓰기를 넣거나 「의제①」처럼 원문자를 쓰면 휴대폰이 의결 화면을 켜지 않는다. 폼이 이런 제목은 만들지 않고 막는다. 휴대폰이 이 모양을 보고 넘김식 화면을 켠다. 건수 「(19건)」은 제목에 넣지 않는다(화면이 붙인다) |
| 안내문 | 비운다 |
| 대상 | **「세션 전체」**를 누른다. 분과를 누르면 그 분과 명단만 투표할 수 있고, 결과 내보내기가 그 투표지를 거부한다 |
| 의제 | 아래 3절의 붙여넣기로 채운다 |

## 3. 19·28·23건 붙여넣기

1. 「여러 건 한 번에 붙여넣기」 칸에 확정 제목 목록을 붙여 넣는다. 한 줄에 한 건이고 모양은 `1-1-안1 권고 제목`이다. 번호 앞자리는 의제 번호와 같아야 한다.
2. 「누르지 않은 건 허용(그 건은 기권으로 기록)」 체크는 쓰지 않는다. **기권 불인정으로 확정(11/10 주최 결정).**
   - 제목이 「전체회의 의결」로 시작하면 체크가 꺼진 채 잠기고 「전체회의 의결 투표지는 모든 건을 눌러야 제출됩니다(기권 불인정)」가 뜬다.
   - 제목을 쓰기 전에 체크를 켰더라도 [초안 만들기] 때 모든 건이 필수로 들어간다.
   - 휴대폰은 모든 건을 눌러야 제출된다. 빠진 건이 있으면 [제출하기]가 꺼지고 첫 미응답 건으로 가는 단추가 뜬다.
3. [붙여넣은 줄로 아래 의제 바꾸기]를 누른다. 아래 목록이 그 줄 수만큼 「찬반(2점)」으로 채워진다.
4. 확인할 것
   - 목록의 마지막 번호가 19·28·23인가. 빈 줄은 버려진다.
   - 노란 「점검」 상자가 비어 있는가. 상자에 뜨는 경우는 대상이 분과, 2점이 아닌 문항, 번호 모양이 다른 줄, 다른 의제 번호다. 상자가 비어야 [초안 만들기]가 된다.
5. [초안 만들기] → 목록에서 「전체」 배지와 문항 수를 확인 → [투표 시작].

붙여넣기 칸을 쓸 수 없으면 [＋ 의제 추가]로 한 건씩 넣는다. 이때는 건마다 「찬반(2점)」을 눌러야 한다. 기본값이 5점이기 때문이다.

「세부권고 보기」 접기는 **넣지 않음(화면 무거움, 11/10 결정 · 20_투표_최종안 W09).** 이 폼에는 세부권고(description) 칸이 없어 휴대폰에는 권고 번호와 제목만 나온다. 세부권고 적재 스크립트도 만들지 않는다.

## 4. 투표 중 · 뒤

- QR은 투표지마다 다르다. 의제 순서대로 하나씩 연다.
- 휴대폰에 「명단이 아직 준비되지 않았습니다」가 뜨면 그 사람의 표는 들어가지 않은 것이다. 명단 · 실명 수집을 고친 뒤 「다시 확인」을 누르게 한다.
- 「이미 이 이름으로 제출되었습니다」가 뜬 시민은 다시 투표할 수 없다. **재투표 불가로 확정(11/10 주최 결정).** 휴대폰도 「같은 이름으로는 다시 투표할 수 없습니다」라고 알린다.
  - 서면 투표지로 대신 받지 않는다. 먼저 낸 휴대폰 표와 겹쳐 한 사람이 두 표가 된다.
  - 남의 이름을 잘못 누른 경우면 자기 이름으로 고쳐 낸다.
  - 낸 적이 없다고 하면 손을 들게 하고 기록원이 조 · 이름 · 시각을 적는다. 결과 내보내기에는 특정 응답을 빼는 입력이 없다.
- 「명단에 없어요 — 이름 직접 입력」으로 낸 표도 유효표로 센다(11/10 주최 결정). **단 출석부 파일(`attendance_file`)에 같은 조 · 이름이 있을 때만 센다(방어선).**
  - 출석부 = 출석한 사람 전원(명단에서 출석한 사람 + 진행요원이 얼굴을 보고 확인한 직접 입력자). 직접 입력자는 휴대폰에서 고른 조 그대로 적는다.
  - 출석부를 주지 않으면 직접 입력 표는 하나도 세지 않는다. 출석부 사람 수가 출석 수보다 적으면 결과 파일이 만들어지지 않는다(직접 입력자만 적은 출석부를 막는다).
  - 같은 이름(띄어쓰기 · 대소문자 무시)이 이미 나왔으면 뒤의 것은 빠진다. 명단에서 고른 이름과 직접 입력이 같은 규칙이다.
  - 결과 요약 txt 의 의제마다 「직접 입력」 목록이 있다. 「유효:」 줄과 「확인 목록:」 줄(세지 않은 표 · 사유)을 검증자가 한 줄씩 본다. 확인 목록에 출석을 확인한 사람이 있으면 출석부 줄(조 · 이름)을 고쳐 다시 돌린다(1분 안).
  - **출석 수에는 센 직접 입력자도 넣는다.** 빠지면 「휴대폰 유효표 + 서면 > 출석」으로 결과 파일이 만들어지지 않는다.
- 휴대폰 표에 누르지 않은 건이 하나라도 있거나, 투표지에 필수가 아닌 문항이 있으면 결과 내보내기가 **파일을 만들지 않고** 그 응답(조 · 이름 · 시각 · 빠진 번호)이나 문항 번호를 적는다. 조용히 빼지 않는다. 이 폼으로 만든 투표지에서는 생기지 않는다(서버가 빈 답을 받지 않는다). 생기면 원자료를 확인하고 주최와 처리를 정한다 — 응답 하나만 빼는 입력은 없다.
- 결과 내보내기는 `scripts/export-result-v2.mjs`로 한다(계약 = `docs/result-v2-contract.md`). 명단은 세션 전원이다. 투표지에 분과 지정이 남아 있으면 파일을 만들지 않는다.
