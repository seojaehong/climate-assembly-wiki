# 0704 현장 사용매뉴얼

이 매뉴얼은 현장 담당자에게 시트입력, 폼입력, 출력 세 가지 메뉴만 안내한다. 담당자가 직접 실행할 명령어는 매뉴얼에서 제외한다.

## 공통

- 관리자 메뉴: https://climate-assembly.org/0704-admin/
- 현장 매뉴얼: https://climate-assembly.org/0704-admin/operator-manual
- 비밀번호: `climate2026`

## 1. 시트입력

기록모더레이터 A/B가 사용한다.

- A/B 입력 Sheet: https://docs.google.com/spreadsheets/d/1aA0h2wUuKydj-RC7ZeD-bI-9C-7f1MQhe_78t7pA4JQ/edit
- A조 담당: `A조 질문입력`, `A조 의제입력`
- B조 담당: `B조 질문입력`, `B조 의제입력`
- 질문은 질문 탭에, 투표 후보 의제는 의제 탭에 한 줄씩 입력한다.

## 2. 폼입력

참여단 또는 조별 응답자가 QR로 입력한다.

- 탄소 감축 질문: https://docs.google.com/forms/d/e/1FAIpQLSeH8fIX-Mjha32u1osfa_aQ2fM8OxAWUCg6_kZsFF33WsCaqA/viewform
- 조별 의제 입력: https://docs.google.com/forms/d/e/1FAIpQLSf6irdECaMygffockxbuSxhsCxOG9WExkxHhtspZT4FhlmouQ/viewform
- 의제투표: https://docs.google.com/forms/d/e/1FAIpQLSf9-AIDhnd0cy8Dfu-xXOgz6cQINjpA-tLzHdM2Ypk8qU_eMA/viewform
- 17~18시 소감발표: https://docs.google.com/forms/d/e/1FAIpQLSccOoHa2gSgIm2EUGqq4zrzkBpr1C6ptsx9HpfYdYLjebINmg/viewform

## 3. 출력

출력 담당자가 관리자 메뉴에서 PDF 버튼을 눌러 인쇄한다.

- 관리자 메뉴: https://climate-assembly.org/0704-admin/
- 질문 PDF: https://climate-assembly.org/0704-admin/live-sheet-questions-print.pdf
- 의제 PDF: https://climate-assembly.org/0704-admin/live-sheet-agendas-print.pdf
- 결과 버블레이스: https://climate-assembly.org/agenda-vote-0704/index.html?sheet=1wbAwRa7ynC12SanI7VJWc-fMea_NmOPVvIAKBLt5Wrw
