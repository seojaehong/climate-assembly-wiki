다국어 로드맵

climate-assembly.org 다국어 로드맵

본 사이트는 한국 기후시민회의를 국제 연구자·정책 입안자도 인용·검증할 수 있는 다국어 디지털 아카이브로 운영합니다. 이 문서는 어떤 언어를, 언제, 어떤 신뢰도 라벨로 공개할지에 대한 단계별 계획을 정리합니다.

현 상태 (2026-06-01)

언어코드상태비고
한국어ko✅ Master모든 페이지 author-verified, 약 50페이지
영어en🟡 부분 공개의제 ⑮ 1건 + About 1건 + En-ROADS 영문 원본·overview·tech-ref summary 30+ 페이지. 콘텐츠 없으면 한국어 본문 + EN 헤더·푸터·배너로 폴백
일본어ja⏸ 비공개M4(2026-09) 이후 시작 예정
중국어(간체)zh-CN⏸ 비공개동상
스페인어es⏸ 비공개동상

현재 astro.config.mjs의 i18n.locales는 ['ko', 'en'] 만 활성화되어 있습니다. ja/zh/es 경로(/ja/... 등)에 직접 접근하면 404가 반환됩니다. 이는 의도된 동작이며, M4 시점에 콘텐츠와 함께 다시 활성화됩니다.

마일스톤별 단계

M2 (현재, 2026-06) — 한·영 dual 입문

  • 한국어 master 약 50페이지 완성도 ↑
  • 영어 의제 14건 영문 쇼케이스 작업 시작 (sub-priority 순서: ①②⑭ → ⑬⑪⑩ → ⑨⑧⑦ → ④③⑥ → ⑫⑤)

M3 (2026-08) — 한·영 안정화

  • DNS climate-assembly.org 연결
  • 영문 의제 14건 + 주요 doc 페이지 완성
  • robots.txt Allow + SEO 본격 시작
  • 사이트 외부 공개 (논문·해외 학회 인용 가능 수준)

M4 (2026-09) — 일·중·서 입문

  • 일본어: 최소 도메인 (About, 의제 ⑮, En-ROADS 18레버, 모더레이터 가이드 5건)
  • 중국어 간체(zh-CN): 동상
  • 스페인어: 동상
  • 우선순위: 일·중 > 서 (동아시아 정책 연구자 우선, 라틴아메리카는 후순위)
  • astro.config.mjs의 i18n.locales에 ja/zh/es 복원, LanguageToggle.astro 옵션 추가

M5~M9 (2026-10 ~ 2027-초)

  • 다국어 콘텐츠 누적 (의제·강의·회차 기록)
  • native 검수자 확보 (대학·외교부·국제기구·재외동포 네트워크 연계)
  • 트러스트 라벨 단계적 격상: machine → reviewed → native-verified

M10+ (2027~) — 5개국어 풀 + 확장

  • 한·영·일·중·서 5개국어 모두 의제 ①~⑮ 완성
  • 차차 추가 5개국어 검토 (불·독·이·아·포 = 프랑스어·독일어·이탈리아어·아랍어·포르투갈어)

신뢰도 라벨 정책

각 페이지 frontmatter의 translations 블록은 언어별 신뢰도를 명시합니다.

언어M3 디폴트M4 이후 목표
한국어 ko🟢 author-verified유지
영어 en🔵 reviewed → 🟢 author-verified유지
일본어 ja⚠️ machine → 🔵 reviewed🟢 native-verified
중국어 zh동상동상
스페인어 es동상동상

라벨 정의는 사이트 소개의 “다국어 정책” 항목을 참고하세요.

콘텐츠 작성 정책 — Author-time Multilingual

  • 모든 다국어 페이지는 메인 세션에서 모더레이터+Claude가 함께 작성·검토 후 한 번에 push 합니다.
  • 빌드타임 자동 번역(MT) 파이프라인은 폐기 (2026-05-31 결정).
  • 이유:
    1. 기계 번역의 사실 오류·맥락 누락 위험 (특히 법령명·정책명·고유명사)
    2. 학술 인용 가능성을 보장하려면 사람 검수가 전제
    3. 부분적 다국어가 잘못된 다국어보다 신뢰도가 높음

자원봉사·협업 모집

  • 일·중·서 native 검수자: 모집 중 (M4 시작 전 확보 목표). 관심 있는 분은 GitHub Issues 또는 모더레이터 이메일로 연락 주세요.
  • En-ROADS 한국어 UI 자원봉사: 진행 중. Climate Interactive에 정식 한국어 로컬라이제이션 요청 발송, 회신 대기.
  • 기타 외국어 검수: M4 시점에 추가 모집 예정.

인용 시 권장 형식

  • 한국어 페이지 인용 권장 URL: https://climate-assembly.org/ko/...
  • 영문 인용: https://climate-assembly.org/en/...
  • 라이선스: 모든 다국어 콘텐츠는 한국어 master와 동일한 CC BY-SA 4.0.
  • DOI 발급 검토: M9+ 시점에 Zenodo 등록 등 영구 보존 식별자 도입 검토.

변경 이력

  • 2026-05-31: M3 MVP는 한·영만 공개로 결정(블로커 M2-②). 일·중·서 라우팅 비공개로 전환.
  • 2026-05-31: 빌드타임 MT 파이프라인 폐기, Author-time Multilingual 정책 채택.
  • 2026-06-01: 본 로드맵 페이지 신설.
