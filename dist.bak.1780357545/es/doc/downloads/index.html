다운로드 센터

본 사이트의 작업산출물(우리가 작성한 한국어 정리본)과 외부 원자료(영문 PDF 등)를 한곳에 모았습니다.

각 자료의 라이선스를 확인하고, 재사용 시 조건(출처 표기·동일 라이선스·비상업·변형금지 등)을 반드시 준수해 주세요. 라이선스가 명확하지 않거나 원저작권자의 별도 허가가 필요한 자료는 사본을 배치하지 않고 원문 링크만 제공합니다.

1. 우리 작업산출물 (CC BY-SA 4.0)

본 사이트가 직접 작성한 한국어 자료입니다. 출처 표기 + 동일 라이선스(CC BY-SA 4.0) 조건으로 자유롭게 인용·재배포·번역·개작할 수 있습니다.

모더레이터교재_원자료_한국어 폴더(19개 페이지, 135 KB 분량의 한국어 정리본)는 본 사이트의 각 문서(/doc, /agenda 등)에 통합되어 있어 별도 압축본을 제공하지 않습니다.

2. 외부 원자료 — 사본 배포 가능 (라이선스 충족)

원저작권자의 라이선스가 비상업·동일 라이선스·출처 표기 조건을 충족하여, 본 사이트가 사본을 재배포할 수 있는 자료입니다. 원문 페이지 방문이 항상 가장 정확합니다.

라이브 데이터

매주 자동 갱신되는 외부 데이터 소스입니다. 다운로드가 아닌 실시간 조회 자료입니다.

  • 시민 발의 의제 트래커 (매주 월 08:00 자동 갱신) → /ko/doc/citizen-proposals-tracker/
  • 구글 시트 직접 보기 → Google Sheets

원자료는 climatevoice.kr (국가기후위기대응위원회 공식 포털). 가공·태깅은 본 사이트(CC BY-SA 4.0).

5. 추가 자료 요청·기여 방법

본 사이트는 1인 운영 + 자원봉사 모델로 운영되며, 자료 추가는 점진적으로 이루어집니다.

  • 자료 요청: 여기 없는 자료를 찾으시면 GitHub 이슈에 남겨 주세요.
  • 번역 기여: 한국어 자료의 다국어 번역(영어·일본어·중국어·스페인어 등) 기여를 환영합니다. About 페이지의 기여 가이드를 참조해 주세요.
  • 오류 신고: 내용 오류·오탈자·링크 깨짐도 GitHub 이슈로 알려 주시면 감사하겠습니다.
