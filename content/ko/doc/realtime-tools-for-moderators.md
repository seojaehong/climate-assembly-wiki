## 모더레이팅 실시간 도구 가이드 — 16종 + 권장 조합

### 1. 왜 이 페이지인가

김상규 2교시 강의([`/ko/doc/lecture-2-kim-sang-gyu/`](/ko/doc/lecture-2-kim-sang-gyu/), 2026-05-31)에서 다음과 같은 문제 제기가 있었다.

> "180명이 자기 핸드폰에서 날리면 그게 주르륵 올라와 가지고 중앙 화면에 이게 막 올라가는 거. 어떻게 하면 좋을지 비주얼하게 만드는 거… 경험 있는 분 팁 주시면 좋겠다."

운영진의 공식 도구 선정은 아직 미정(2026-06-01 기준)이다. 본 페이지는 **모더레이터가 자기 분임 12명을 운영하는 데 즉시 활용할 수 있는 도구 16종**을 4개 카테고리로 정리하고, 회기별 권장 조합을 제시한다. 우리 사이트 자체 구현 한계는 후속 페이지 [`/ko/doc/realtime-tools-implementation-guide/`](/ko/doc/realtime-tools-implementation-guide/) 에서, **실제 계정 생성·요금제 결정·질문 풀·현장 운영 매뉴얼은** → [`/ko/doc/realtime-tools-setup-cookbook/`](/ko/doc/realtime-tools-setup-cookbook/) (세팅 쿡북) 에서 다룬다.

---

### 2. 김상규 강의에서 직접 언급된 옵션

- **구글폼 + Excel 실시간 그래프** — 김상규 1순위. "가장 편하다, 즉시 가능"
- **Kahoot!** — 1 위원이 제안 (게임형 응답)
- **En-ROADS** — 7월 4일 4차 본회의에서 시뮬레이터 실연 예정. 한국어 미지원 → MS Edge 자동 번역 사용
- **핸드폰 → 중앙 화면 시스템** — 허현 위원·고현 위원·코리아스픽스·빠띠가 각각 제안

### 4. ★ 권장 조합 (회기별)

#### 분임 세션 (12명 × 5조 × 3분과 = 180명)

- **Mentimeter** 또는 **구글폼** — 시민 발언 실시간 수집 → 모더레이터 노트북에 띄움
- **En-ROADS** (MS Edge 자동 번역) — 시뮬레이터 직접 조작
- **우리 모더레이터 카드 v1** — A4 출력, 분임 책상 비치

#### 전체회의 (7.4 4차, 10.17 8차, 200명 규모)

- **Slido** 또는 **빠띠(Parti)** — 200명 핸드폰 응답 → 메인 스크린 송출
- **POL.IS** — 후반 합의 도출 단계에서 의견 클러스터링

#### 합숙 워크숍 (6.13~14, 9.12~13)

- **Miro** 또는 **Mural** — 디지털 포스트잇으로 의견 시각화
- **우리 의제 매트릭스 v5** — 분과 격자 출력본 병행

### 5. POL.IS 심화 — 시민의회 모범 사례

POL.IS는 시민의회 운영에서 사실상의 글로벌 표준이다.

- 의견 자동 클러스터링 + 동의/비동의 매핑
- **"동의하기로 동의하지 않은 것(disagreed to disagree)"** 식별 → 모더레이터의 다음 액션 도출에 직접 활용
- 사례: 대만 vTaiwan (2014~, 200+ 정책 합의), 핀란드 정부, Climate Assembly UK
- 오픈소스(AGPLv3), 자체호스팅 가능 → 우리 사이트 통합 가능성은 후속 페이지 참조

---

### 6. 운영진 미해결 사항

김상규 강의에서 명시적으로 "팁이 필요하다"고 한 부분이다. 운영진(코리아스픽스 등) 측에서 도구를 선정하면 본 페이지를 갱신한다. 그때까지 모더레이터는 위 권장 조합 중 자신에게 익숙한 도구를 선택해 분임 운영에 사용한다.

후속 페이지 [`/ko/doc/realtime-tools-implementation-guide/`](/ko/doc/realtime-tools-implementation-guide/) — 오픈소스 vs 유료 비교, 우리 사이트(climate-assembly.org) 도입 한계 검토.
