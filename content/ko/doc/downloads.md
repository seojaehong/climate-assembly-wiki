# 다운로드 센터

본 사이트의 작업산출물(우리가 작성한 한국어 정리본)과 외부 원자료(영문 PDF 등)를 한곳에 모았습니다.

각 자료의 **라이선스**를 확인하고, 재사용 시 조건(출처 표기·동일 라이선스·비상업·변형금지 등)을 반드시 준수해 주세요. 라이선스가 명확하지 않거나 원저작권자의 별도 허가가 필요한 자료는 **사본을 배치하지 않고 원문 링크만** 제공합니다.

## 5. 추가 자료 요청·기여 방법

본 사이트는 **1인 운영 + 자원봉사 모델**로 운영되며, 자료 추가는 점진적으로 이루어집니다.

- **자료 요청**: 여기 없는 자료를 찾으시면 [GitHub 이슈](https://github.com/seojaehong/climate-assembly-wiki/issues)에 남겨 주세요.
- **번역 기여**: 한국어 자료의 다국어 번역(영어·일본어·중국어·스페인어 등) 기여를 환영합니다. [About 페이지](/doc/about)의 기여 가이드를 참조해 주세요.
- **오류 신고**: 내용 오류·오탈자·링크 깨짐도 GitHub 이슈로 알려 주시면 감사하겠습니다.
