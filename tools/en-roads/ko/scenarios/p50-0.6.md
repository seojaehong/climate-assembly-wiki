# 시나리오 해설 — `p50=0.6`

> 원본 URL: <https://en-roads.climateinteractive.org/scenario.html?v=26.5.0&p50=0.6>

## 1. 이 시나리오의 정체

이 URL은 En-ROADS v26.5.0에서 **단일 슬라이더(파라미터 `p50`) 하나만** 값 `0.6` 으로 이동시키고, 나머지 17개 슬라이더는 모두 status quo 위치에 둔 시나리오입니다.

**중요한 솔직한 한계:** `p50`이 정확히 어떤 슬라이더(석탄? 재생에너지? 탄소가격? 폐기물·누출?)에 해당하는지는 En-ROADS의 외부 공개 매핑 표만으로는 단정할 수 없습니다. 파라미터 번호(p1, p2, ...)는 모델 내부 인덱스이며, 모델 버전 업그레이드 시 변경된 사례도 있습니다.

**정확한 식별 방법** — 시뮬레이터에서 위 URL을 직접 열고:
1. 어떤 슬라이더가 status quo에서 벗어나 0.6 위치에 있는지 시각적으로 확인.
2. 해당 슬라이더 옆 "i" (정보) 버튼을 눌러 슬라이더 이름과 단위 확인.
3. 그 슬라이더 이름을 본 위키 `ko/18-levers.md` 에서 찾아 해당 항목 적용.

## 2. 값 `0.6` 의 의미 해석

슬라이더마다 값 의미가 다릅니다:

- 만약 **에너지원 가격조정 슬라이더**(석탄/가스/석유/재생/원자력/바이오)라면 `0.6` = +60% 세금. 해당 에너지원을 강하게 디스카운트(highly discouraged 영역).
- 만약 **에너지 효율 슬라이더**라면 `0.6` = 연 0.6% 효율 개선. status quo(1.0~1.7%) 보다 낮음 — **효율 개선 후퇴** 시나리오.
- 만약 **인구 슬라이더**라면 `0.6` = UN 범위 중간 부근 (status quo 인근).
- 만약 **탄소가격 슬라이더**라면 `0.6` 은 일반적으로 정규화된 위치(0~1)일 가능성 → 중간 정도 가격.

## 3. 모더레이터가 시민에게 어떻게 안내할까

이 시나리오 링크가 토론 중에 공유되었다면, 다음 절차를 추천합니다:

1. **링크 열기** — 화면 공유 후 어떤 슬라이더가 움직였는지 같이 확인.
2. **읽기** — "이 시나리오는 \[슬라이더 이름]만 \[위치]로 옮긴 단일 레버 시나리오입니다" 라고 명확히 설명.
3. **결과 확인** — Temperature Change, Sources of Primary Energy, GDP Loss 등 핵심 그래프를 베이스라인과 비교.
4. **단일 레버 함정 짚기** — 시민회의의 핵심 학습 중 하나는 "한 가지 레버만으로는 충분하지 않다"는 발견입니다. 이 시나리오로 그 발견을 유도하기 좋습니다.

## 4. 시민이 자주 묻는 것

- **Q. "이게 한국 정책이에요?"**  
  A. 아닙니다. En-ROADS는 전 지구 합산 모델입니다. 이 시나리오는 "전 세계가 동시에 이 레버를 움직이면 이런 그림이 됩니다"의 의미입니다.

- **Q. "그럼 우리는 뭘 결정하나요?"**  
  A. En-ROADS 토론은 방향성 합의입니다. 구체적 한국 정책은 환경부·산업통상자원부와의 후속 실무회의에서 다듬어집니다.
