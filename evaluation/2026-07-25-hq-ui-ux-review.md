# `/hq` 본부 관제 화면 UI/UX 검토

- 검토 시각: 2026-07-25 00:59 KST
- 라이브 대상: `https://climate-assembly.org/hq/`
- 검토 범위: 프로덕션 렌더링, 데스크톱·좁은 화면, 정보 위계, 조 선택과 상세 탐색
- 코드 수정: 없음

## 결론

현재 `/hq`는 15개 조의 상태와 참여 인원을 읽는 최소 상태판으로 동작한다. 그러나 데스크톱에서 핵심 정보가 잘리고, 15개 카드가 한 화면에 들어오지 않으며, 카드가 선택 불가능해 조별 질문·투표 결과·권고내용을 탐색할 수 없다.

다음 버전의 기본 상호작용은 **조 카드 단일 선택 → 상세 패널**로 잡는 것이 적합하다. 여러 조 비교는 상시 체크박스가 아니라 별도의 **비교 모드**로 제공한다.

## 라이브 검증

- HTTP 200, 타이틀 `기후시민회의 운영 현황 [/hq]`
- 15개 조 로딩 정상
- 검토 시점 상태: 15개 조 모두 `대기`, 참여 `0/20`
- 실시간 갱신 시각 표시 정상
- 브라우저 콘솔 앱 오류 미발견
- 카드에 버튼·링크·키보드 포커스 요소 없음

## 발견 사항

### P1 — 데스크톱 5열에서 조 이름과 참여 수가 깨진다

- 1440px 화면에서 카드 폭은 약 255px이다.
- 조 이름은 `truncate` 처리되어 `1분...`처럼 보인다.
- 참여 수는 80~92px 고정 글자 크기여서 `0/20`이 `0/2`와 `0`으로 줄바꿈된다.
- 15개 카드의 전체 높이는 약 1,246px이므로 일반적인 본부 화면에서 세 행을 한 번에 볼 수 없다.

근거:

- `src/islands/mod/HqGrid.tsx:40` — 조 이름 36~40px + `truncate`
- `src/islands/mod/HqGrid.tsx:57` — 참여 수 80~92px
- `src/islands/mod/HqGrid.tsx:121` — 대형 화면 5열

권장:

- 5×3 구조는 유지하되 카드를 상태판용으로 압축한다.
- 조 이름 24~28px, 참여 수 44~56px, 카드 높이 약 160~190px.
- 참여 수에 `whitespace-nowrap`과 tabular number를 적용한다.
- `1분과 1조` 전체 이름은 줄임표 없이 표시한다.
- 상단 요약 영역과 15개 카드를 1080p 한 화면에 수용한다.

### P1 — 조 선택과 상세 확인 경로가 없다

현재 카드는 표시용 `div`이고 버튼·링크·`role`·`tabIndex`가 없다. 조별 질문, 보기, 결과, 권고내용으로 이동할 수 없다.

근거:

- `src/islands/mod/HqGrid.tsx:33-61` — `TeamCard`가 비대화형 `div`
- `src/islands/mod/HqGrid.tsx:65` — 읽기전용 표시만 한다는 기존 범위

권장 기본 동작:

1. 조 카드를 클릭하거나 Enter/Space로 선택한다.
2. 데스크톱에서는 오른쪽 상세 drawer, 좁은 화면에서는 전체 폭 sheet를 연다.
3. 선택된 카드는 굵은 테두리와 `선택됨` 상태를 텍스트로도 표시한다.
4. URL에 `?team=<team-id>`를 반영해 새로고침·공유·현장 인수인계가 가능하게 한다.
5. Esc/닫기 버튼으로 전체 15조 개요로 복귀한다.

### P1 — 권고내용의 authoritative source가 현재 `/hq` 데이터 계약에 없다

현재 `/hq`가 가져오는 데이터는 팀, 라운드, 라운드별 총 투표 수다. 라운드에는 질문 제목과 보기가 포함되므로 **현재/최근 질문과 선택지**는 DB 변경 없이 상세 패널에 표시할 수 있다.

하지만 조별 **권고안 원문**을 어떤 데이터에서 어떤 조와 연결할지는 현재 `HqGrid` 계약에 없다. 권고안을 임의로 라운드 제목이나 1위 보기로 간주하면 안 된다.

권장:

- 1차: 기존 `rounds`와 `votes`를 사용해 최근 질문·보기별 집계·참여 현황을 상세 패널에 표시한다.
- 2차: 권고안 원천인 `climate_vote.agenda` 또는 현장 입력 소스에서 조 식별자와 원문 필드를 확인한 뒤 읽기전용으로 연결한다.
- 소스 매핑이 확정되기 전에는 패널 명칭을 `권고내용`이 아니라 `최근 질문·결과`로 둔다.
- DB 스키마 변경이 필요해지면 별도 승인 후 진행한다.

### P1 — 조회 실패가 화면에 드러나지 않는다

데이터 조회 실패 시 빈 `catch`로 무시되어 사용자는 `조 정보를 불러오는 중입니다…` 화면만 계속 볼 수 있다. 현장 장애와 단순 로딩을 구분할 수 없다.

근거:

- `src/islands/mod/HqGrid.tsx:85-87`

권장:

- `연결 실패 · 다시 시도` 오류 상태와 재시도 버튼을 제공한다.
- 마지막 성공 데이터는 유지하고 `마지막 갱신 지연` 경고를 표시한다.
- 실시간 연결, 폴링 중, 연결 지연을 텍스트와 아이콘으로 병기한다.

### P2 — 전체 상황을 요약하는 관제 지표가 없다

15개 카드를 모두 훑어야 투표 중인 조나 문제 조를 찾을 수 있다.

권장 상단 요약:

- `투표 중 n`
- `마감 n`
- `대기 n`
- `참여 저조 n`
- `갱신 지연 n`

상태 필터를 누르면 해당 카드만 강조하고 나머지는 흐리게 표시한다. 색만으로 상태를 전달하지 않고 숫자와 라벨을 함께 쓴다.

### P2 — 조 이름과 분과명이 중복된다

`1분과 1조` 아래에 다시 `1분과`를 표시해 좁은 카드의 공간을 소모한다.

권장:

- 카드 제목은 `1분과 1조`.
- 보조 줄은 최근 활동 또는 질문 요약에 사용한다.
- 분과 필터가 필요하면 상단 탭 `전체 · 1분과 · 2분과 · 3분과`로 이동한다.

## 선택 방식 권고

### 기본: 단일 조 선택

- 현장 본부의 기본 질문은 “어느 조에 무슨 일이 있는가?”이므로 한 조의 맥락을 빠르게 여는 것이 우선이다.
- 카드 전체를 버튼으로 만들고 상세 drawer를 연다.
- 상세를 닫아도 그리드의 스크롤과 필터 상태를 유지한다.

### 보조: 비교 모드

- `비교 모드`를 켰을 때만 카드에 선택 표시를 노출한다.
- 최대 3개 조를 선택한다.
- 비교 항목은 참여율, 상태, 최근 질문, 상위 보기, 최종 갱신 시각으로 제한한다.
- 권고안 원문 전체를 나란히 놓기보다 핵심 요약 후 원문 확장으로 제공한다.

## 권장 구현 순서

1. 데스크톱 카드 글자 잘림·참여 수 줄바꿈·한 화면 밀도 수정
2. 로딩 실패와 갱신 지연 상태 추가
3. 단일 조 선택 + 상세 drawer + URL 상태
4. 기존 라운드 기반 최근 질문·보기별 결과 표시
5. 권고안 원천 데이터의 조 매핑 확인
6. 권고내용 연결
7. 비교 모드 추가

## 검증 게이트

- 1440×900 및 1920×1080에서 15조 개요를 한 화면에 표시
- 390px에서 가로 overflow 없이 카드와 상세 sheet 표시
- 200% 확대에서도 조 이름·참여 수·닫기 버튼이 잘리지 않음
- 키보드만으로 카드 선택·상세 닫기 가능
- 연결 실패·지연·정상 상태를 화면에서 구분 가능
- 권고내용에는 원천, 갱신 시각, 조 매핑 근거가 함께 표시
