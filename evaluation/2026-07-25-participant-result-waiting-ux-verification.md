# 참가자 투표 결과 대기 UX 검증

## 변경 목적

참가자가 투표를 제출한 직후 표시되던 `결과 보기` 버튼이 즉시 결과를
열 수 있는 기능처럼 읽히는 문제를 수정했다. 실제 결과 공개 조건인
`모더레이터의 투표 마감`을 완료 화면에서 명확히 안내한다.

## 변경 사항

- 제출 직후 제목을 `투표가 제출되었습니다`로 변경
- `투표 제출 완료 → 투표 마감 후 결과 공개` 2단계 상태 안내 추가
- `결과 보기`를 `투표 마감 여부 확인`으로 변경
- 투표 진행 중이면 `아직 투표가 진행 중입니다. 마감 후 다시 확인해 주세요.` 안내
- 네트워크 확인 실패 시 제출 완료 화면을 유지하고 재시도 안내 노출
- 상태 안내에 `aria-live="polite"` 적용, 확인 버튼 높이 56px 확보
