## PM 확인 전 반영 금지

1. `A·B·C·D` 유형은 잠정 설명이고 C 유형도 보류 발언이 있어, 현 한글 정본의 “사용 안 함”을 유지한다.
2. 분과별 주제 수는 본회의의 `9·8·8`과 후속 대화 일부 발언이 충돌한다. 새 HWP의 실제 목록으로 다시 센다.
3. 조별 최소 주제 수는 `2개`와 `4개`가 모두 제시됐으나 확정되지 않았다. 화면에 숫자를 고정하지 않는다.
4. 주제 자동 배정과 공개 대화면은 회의에서 우려가 제기됐다. 책임 모더레이터의 자율 배정을 우선한다.
5. 후속 일정의 `10월 17일`과 `10월 27일`은 서로 다른 회의를 뜻할 가능성이 있으므로 화면·문서 날짜를 바꾸지 않는다.
6. 검증되지 않은 “관련 조” 연결은 배정 근거나 시스템 판단에 쓰지 않는다.
