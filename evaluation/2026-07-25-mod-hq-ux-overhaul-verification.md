- OS 다크 모드에서도 콘솔은 의도된 라이트 팔레트로 표시된다.

- 조 카드를 네이티브 버튼으로 바꾸고 상세 패널을 추가했다.
- 선택한 조를 `team` URL 파라미터에 보존해 새로고침과 브라우저 이동에서 복원한다.
- 최근 질문, 상태, 참여, 선택지별 득표, 선두 선택지, 갱신 시각을 보여준다.

팀 카드는 접근성 트리에 버튼으로 노출되어 Enter·Space 기본 동작을 상속한다. 상세 닫기 버튼에 초기 포커스를 주고 Escape 닫기를 제공한다.

현재 라이브 시드에는 진행 또는 마감된 라운드가 없어 실브라우저 상세에서는 “아직 진행된 조별 투표가 없습니다”가 정상 표시됐다. 선택지별 득표·선두·공동 선두·무득표 경로는 결정론적 단위 테스트로 검증했으며 라이브 DB에 테스트 투표를 만들지 않았다.

## 실배포 검증

- Cloudflare Git 연동 배포가 장시간 Active 상태에서 완료 URL을 내지 않아 검증된 `dist`를 Wrangler 백업 경로로 배포했다.
- Node 22 + Wrangler 4.114.0에서 16,267개 파일 업로드와 Functions bundle 배포가 성공했다.
- 커스텀 도메인의 HQ 자산이 이전 `HqGrid.TFb6XpHf.js`에서 최종 `HqGrid.CG6Is15V.js`로 전환된 것을 확인했다.
- 실도메인 `/mod/`, `/hq/`, `/v/`, `/mod-help/`, `/robots.txt`가 모두 HTTP 200을 반환했다.
- 실도메인 `/hq/index.html`에서 15조, 상세 URL 복원, Escape 닫기, 3조 비교, 4번째 선택 제한을 다시 통과했다.
- 실도메인 `/mod/index.html`에서 타이틀, 6자리 접속 화면, `422040` 입장, 투표·타이머 화면, 다크 모드, 가로 오버플로 없음을 확인했다.
- 현재 실도메인에서 새로 발생한 브라우저 오류는 없었다. 로그에 남은 HQ 오류 1건은 로컬 오프라인 복구 시험에서 의도적으로 만든 과거 로그다.
