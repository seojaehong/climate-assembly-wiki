# 별도 에이전트 검증 기록

생성 시각: 2026-07-04

## 검증 범위

사용자 요청에 따라 별도 에이전트 두 개를 읽기 전용으로 실행했다.

- 입력 누락 검증 에이전트: 원본, 전사, 그래프, 7.4 투표/결론 산출물 사이의 누락·부분 반영 여부 확인
- UX/온톨로지 검증 에이전트: 공개 메뉴가 A조만 부각하지 않는지, 전체 과정에서 최종 결론으로 이어지는 구조인지 확인

## 입력 누락 검증 결과

검증 에이전트 판정은 다음과 같다.

- 전체 입력 흐름을 보여주는 coverage/결론 그래프는 있다.
- 모든 원본 입력이 graph/conclusion ontology에 완전 반영된 상태는 아니다.
- A조만 들어간 것은 아니다. A조, B조, 통합/발표/교육 세션이 통합 그래프에 함께 있다.
- 부분 또는 gap 항목은 `B_t2`, `토론4통합`, `음성002`다.

검증 중 지적된 보정 사항과 반영 결과:

| 지적 | 조치 |
| --- | --- |
| `reg-article14-direct-indirect` report boolean이 그래프 연결과 불일치 | `reflected_in_existing_regulation_graph` 판정을 match 존재 기준으로 수정 |
| `전사·텍스트 세션 13건` 표현이 부정확 | `음성·문서 세션 13건 + 텍스트 세션 6건`으로 수정 |
| `inputs` 폴더를 m4a-only 전체 coverage 근거처럼 쓰면 안 됨 | 입력 감사 보고서에서 workflow input markdown과 source coverage를 분리 |

## UX/온톨로지 검증 결과

검증 에이전트 판정은 다음과 같다.

- 공개 기본 진입점은 `전체 과정 → 최종 결론`이다.
- 공개 메뉴에는 `live-A_t1` 항목이 없다.
- `index.html`은 `sources.sources`에 등록된 소스만 드롭다운과 URL source로 로딩한다.
- 프로세스 온톨로지는 원본자료, 전사, 통합 워크숍 그래프, 투표·발표자료, 최종 결론 흐름을 가진다.

검증 중 지적된 보정 사항과 반영 결과:

| 지적 | 조치 |
| --- | --- |
| `public/workshop-graph/data/live-A_t1.json` 직접 접근 가능성 | public 배포 대상에서 파일 삭제 |
| final/process 화면 footer가 `LLM 추출 · 인간 검증 전`으로 보일 수 있음 | final variant footer를 `검증 산출물 기반 · 미완/갭 항목 별도 표시`로 변경 |
| 발표 모드 묶기 라벨이 `A조 의제선정 흐름`을 별도 대목차로 표시 | A/B 세션을 `조별 의제선정 흐름` 상위 묶음으로 통합 |
| 일부 kindKo가 `Claim`, `Condition` 영어로 남음 | 생성 스크립트의 kindKo 매핑에 `Claim`, `Condition`, `Group` 추가 |
